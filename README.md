## The line

> My smart fridge has Wi-Fi, a touchscreen, and a camera inside — yet its smartest move in five years was beeping at me for eating ice cream at 2 a.m. like a disappointed parent.

## How it works

`main.py` writes that single line (176 characters, one line of plain text) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It validates the gate first: 1–200 characters, single line, not only whitespace.

Run it grader-style:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```
